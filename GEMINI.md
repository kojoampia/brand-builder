# brand-builder (Brand Builder)

An AI-powered tool to visualize products across multiple mediums while maintaining consistent branding.

## Project Overview
Brand Builder allows users to conceptualize their products in various contexts, such as billboards, newspapers, and social media posts, ensuring brand identity remains uniform across all generated visuals.

## Tech Stack
- **Frontend:** React with Vite
- **Language:** TypeScript
- **AI Integration:** Gemini API (primarily for image generation orchestration)
- **Styling:** CSS

## Core Workflows
- **Brand Identity Definition:** Defining the core visual elements of a brand.
- **Medium Selection:** Choosing different advertising mediums for visualization.
- **Prompt Engineering:** Generating high-quality prompts for consistent image generation.

## Architecture
- `src/App.tsx`: Orchestrates the brand building and visualization flow.
- `src/main.tsx`: Application entry point.
